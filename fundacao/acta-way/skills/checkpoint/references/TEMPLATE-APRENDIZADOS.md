## Critério de promoção

| Situação | Destino |
|---|---|
| Vale só para este cliente | fica no `CHECKPOINT.md`, não sobe |
| Vale para qualquer projeto **deste tipo** | skill do plugin do projeto |
| Vale para qualquer projeto **desta prática** | `acta-metodo-consultoria` ou `acta-metodo-auditoria` |
| Vale para **toda a firma** | `acta-way` |

Promover é abrir alteração no repositório do plugin no GitHub, subir a versão e avisar a equipe para
rodar `claude plugin update`. Enquanto a lição estiver só aqui, ela não existe para quem não abriu
esta pasta.
