# Outros

Espaço reservado para frentes de conhecimento da ACTA que não se encaixam em **Consultoria** ou
**Auditoria** — por exemplo, Tecnologia, ESG, Jurídico, ou qualquer nova prática que surja.

Nenhuma subsegmentação foi criada aqui ainda. Quando uma nova frente for consolidada, siga o mesmo
padrão de plugin usado em `consultoria/rh/pesquisa-salarial` ou `auditoria/auditoria-interna`:

```
outros/<area>/<subsegmentacao>/
  .claude-plugin/plugin.json
  SKILL.md
  skills/<sub-skill>/SKILL.md   (se houver mais de uma skill)
  references/                   (metodologia, templates)
```
