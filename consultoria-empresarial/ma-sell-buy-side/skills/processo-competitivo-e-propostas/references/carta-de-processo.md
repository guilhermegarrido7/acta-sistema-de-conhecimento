# Carta de processo e comparativo de propostas: modelos

Apoio da skill `processo-competitivo-e-propostas`. Estrutura e conteúdo econômico das cartas; as
reservas e qualquer texto com efeito jurídico são revisados pela assessoria jurídica do vendedor
antes do envio. Nenhuma carta sai sem autorização do vendedor e do sócio responsável.

Convenções de redação: as mesmas da carta de `solicitacao-de-informacoes` (rubrica em caixa alta,
item como objeto pedido, pontuação de lista com `;`, `; e` e `.`). Nome do alvo não aparece: a carta
usa o codinome do projeto (ver `convencoes-de-projeto`).

## 1. Carta da 1ª fase (proposta não vinculante)

```
[timbrado da assessoria]
<data por extenso>

<Razão social do proponente>
Att. <destinatário que assinou o NDA>

Assunto: Projeto <codinome> | Carta de processo, 1ª fase

Prezado(a)s,

<parágrafo de enquadramento>

1. MATERIAL DISPONIBILIZADO
2. CRONOGRAMA
3. CONTEÚDO DA PROPOSTA NÃO VINCULANTE
4. ENTREGA
5. CONTATO E CONDUTA
6. PRÓXIMAS FASES
7. RESERVAS DO VENDEDOR
8. CONFIDENCIALIDADE

Respeitosamente,

<razão social da assessoria>
```

**Enquadramento.** Uma frase sobre o papel da assessoria no processo, a remissão ao Acordo de
Confidencialidade assinado (com data) e ao material já entregue. Sem adjetivo sobre o ativo: a
carta é regra, não argumento de venda.

**1. Material disponibilizado.** Lista do que o proponente recebeu: teaser, Information Memorandum,
e, se houver, o conjunto resumido de dados da 1ª fase. Versão e data de cada um.

**2. Cronograma.** A data-limite da NBO com hora e fuso, e a indicação das fases seguintes sem data
fechada, quando o vendedor preferir manter flexibilidade.

**3. Conteúdo da proposta não vinculante.** Itens como objeto pedido:

- Valor proposto, indicando se corresponde a enterprise value ou a equity value, e a data-base;
- Premissas de dívida líquida, caixa e itens assemelhados adotadas na ponte entre os dois;
- Nível de referência de capital de giro suposto;
- Estrutura de pagamento (à vista, diferido, contingente, permuta de participação) e mecanismo de
  preço pretendido (locked box ou completion accounts);
- Fonte dos recursos e grau de compromisso do financiamento;
- Escopo, assessores e prazo pretendidos para a due diligence;
- Aprovações internas e regulatórias necessárias, com o prazo estimado;
- Condicionantes da proposta; e
- Prazo de validade.

**4. Entrega.** Canal (e-mail do responsável na assessoria ou pasta específica no data room),
formato (PDF assinado por representante do proponente) e idioma.

**5. Contato e conduta.** Toda comunicação passa pela assessoria. É vedado o contato com
administradores, empregados, clientes, fornecedores ou financiadores do alvo sem autorização
prévia e escrita. Visita a instalações só nas fases seguintes, agendada pela assessoria.

**6. Próximas fases.** O que a shortlist recebe: data room completo, management presentation,
visita, Q&A e a minuta do contrato preparada pelo vendedor.

**7. Reservas do vendedor.** Conteúdo econômico a garantir: o vendedor pode alterar o cronograma e
as regras, encerrar o processo, rejeitar qualquer proposta sem justificar e negociar com qualquer
parte, e nenhuma obrigação nasce da carta ou da proposta. **A redação é da assessoria jurídica.**

**8. Confidencialidade.** Parágrafo corrido, com remissão ao NDA vigente.

## 2. Carta da rodada vinculante

Mesma estrutura, com três diferenças:

1. **Material disponibilizado** inclui o data room completo (com a data de corte do índice), as
   respostas publicadas do Q&A e a minuta do contrato.
2. **Conteúdo da proposta vinculante**:
   - Preço, base, data-base e mecanismo de preço;
   - Estrutura de pagamento, com garantia de toda parcela não paga no fechamento;
   - Markup da minuta do contrato em controle de alterações, com nota explicativa de cada alteração
     relevante;
   - Evidência do financiamento (carta de compromisso, quando houver dívida);
   - Aprovações internas obtidas e o plano das regulatórias, inclusive a análise de notificação ao
     CADE;
   - Confirmação de que a due diligence está concluída, ou a lista exata do que falta e o prazo;
   - Lista de condições precedentes pretendidas; e
   - Prazo de validade e assinatura por representante com poderes.
3. **Exclusividade**: a carta não promete. Se o vendedor decidir concedê-la, isso acontece depois
   das propostas vinculantes, nos termos de `negociacao-e-loi`.

## 3. Comparativo das propostas

Uma coluna por proponente, uma linha por item, e a coluna de premissa preenchida sempre:

| Linha | Proponente A | Proponente B | Premissa da casa |
|---|---|---|---|
| Headline e base (EV ou equity) | | | |
| (−) Dívida líquida e itens assemelhados | | | Definição de cada proponente, item a item |
| (±) Ajuste de capital de giro | | | Peg da casa e fonte do cálculo |
| (−) Desconto da parcela diferida | | | Taxa e risco de crédito do comprador |
| (−) Desconto do earn-out | | | Probabilidade e taxa, por escrito |
| (−) Desconto de retenções | | | Prazo e probabilidade de liberação |
| **= Equity value comparável** | | | Mesma data-base |
| Parcela à vista no fechamento | | | |
| Financiamento | | | Comprometido, em negociação ou a captar |
| Notificação ao CADE e prazo | | | Leitura preliminar; parecer da assessoria concorrencial |
| Condicionantes | | | Quais dependem só do comprador |
| Escopo e prazo de diligência | | | |
| Prazo estimado até o closing | | | |
| Conduta e histórico | | | Fonte da informação |
| Markup (rodada vinculante) | | | Custo esperado dos desvios, em reais |
| Leitura | | | Uma frase por proponente |

Duas regras de uso:

- **Premissa vazia invalida a linha.** Desconto sem taxa ou probabilidade declarada é opinião.
- **O comparativo é do vendedor.** Ele não circula entre proponentes, nem em versão anonimizada.
